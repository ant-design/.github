## ✨ Features

- 🌈 **Enterprise-class UI** designed for web applications
- 📦 **High-quality React components** out of the box
- 🛡 **Written in TypeScript** with predictable static types
- ⚙️ **Powerful theme customization** in every detail
- 🌍 **Internationalization** support for dozens of languages
- 🎨 **Design resources** and development tools

## 🚀 Our Projects

### Core Libraries

- **[Ant Design](https://github.com/ant-design/ant-design)** - A UI Design Language and React UI library
- **[Ant Design Mobile](https://github.com/ant-design/ant-design-mobile)** - Mobile UI components based on Ant Design
- **[Ant Design Charts](https://github.com/ant-design/ant-design-charts)** - A React chart library based on G2Plot
- **[Ant Design Pro](https://github.com/ant-design/ant-design-pro)** - Out-of-box UI solution for enterprise applications
- **[Pro Components](https://github.com/ant-design/pro-components)** - Advanced components for building professional applications

### Tools & Ecosystem

- **[Ant Design Icons](https://github.com/ant-design/ant-design-icons)** - SVG icons for Ant Design
- **[Ant Design Vue](https://github.com/vueComponent/ant-design-vue)** - Ant Design for Vue.js
- **[Ant Design Angular](https://github.com/NG-ZORRO/ng-zorro-antd)** - Ant Design for Angular
- **[Ant Design Mini](https://github.com/ant-design/ant-design-mini)** - Mini Program UI components

### Design Resources

- **[Ant Design Landing](https://github.com/ant-design/ant-design-landing)** - Landing page templates
- **[Ant Motion](https://github.com/ant-design/ant-motion)** - Animation specification and components
- **[Ant Design Colors](https://github.com/ant-design/ant-design-colors)** - Color palettes
